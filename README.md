## 🧪 How to Run

1. Install [R](https://www.r-project.org/) and optionally [RStudio](https://posit.co/products/open-source/rstudio/).
2. Open any `.R` file in RStudio or run in your terminal using:

```r
source("path/to/file.R")
```

## 📦 Dependencies

Some exercises may require R packages such as:

- `tidyverse`
- `readxl`
- `ggplot2`

Install them with:

```r
install.packages("tidyverse")
install.packages("readxl")
install.packages("ggplot2")
```
